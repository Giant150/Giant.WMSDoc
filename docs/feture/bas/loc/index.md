# 库位管理

&nbsp;&nbsp;&nbsp;&nbsp;1.拣货路顺：按照此顺序进行出库

&nbsp;&nbsp;&nbsp;&nbsp;2.上架路顺：按照此顺序进行上架

&nbsp;&nbsp;&nbsp;&nbsp;3.上架区域：逻辑区域，可对物料上架进行不同物料上架到不同区域

&nbsp;&nbsp;&nbsp;&nbsp;4.区域：所在规划区域
