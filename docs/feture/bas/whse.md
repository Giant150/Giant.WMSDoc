# 仓库管理

对仓库进行数据定义，包含仓库基础信息新增、修改、删除、所属角色，每一个仓库数据都需要添加对应的仓库权限

## 新增、修改

&nbsp;&nbsp;&nbsp;&nbsp;1.编号：仓库所对应的编号

&nbsp;&nbsp;&nbsp;&nbsp;2.名称：仓库所对应的名称

&nbsp;&nbsp;&nbsp;&nbsp;3.类型：仓库所对应的仓库类型

![](./whse/01.png)

## 删除

点击操作表头下的删除按钮，进行删除操作

![](./whse/03.png)

仓库数据设置对应的仓库权限
