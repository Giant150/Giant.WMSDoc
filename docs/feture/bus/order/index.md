# 发货管理

可查询需要发货的物料详细信息；发货管理数据通常由MOM下发发货单，也可人工建立发货单

![](06.png)

## 查询/重置

可根据多个条件进行检索发货单数据/重置所有查询条件

![](01.png)

## 人工建立发货单

&nbsp;&nbsp;&nbsp;&nbsp;1.货主：货主（默认显示当前货主）

&nbsp;&nbsp;&nbsp;&nbsp;2.单据编码：单据编码（点击文本框右侧刷新 **自动生成** ）

&nbsp;&nbsp;&nbsp;&nbsp;3.发货类型：发货类型（根据实际情况选择类型）

&nbsp;&nbsp;&nbsp;&nbsp;4.处理类型：处理类型（根据实际情况选择类型）

![](02.png)

### 添加发货物料

点击新建，生成一栏无数据发货明细

&nbsp;&nbsp;&nbsp;&nbsp;1.编号：点击编号文本框右侧刷新 **自动生成**

&nbsp;&nbsp;&nbsp;&nbsp;2.物料：点击物料文本框选择到货物料

&nbsp;&nbsp;&nbsp;&nbsp;3.订单数量：订单数量

![](03.png)

## 打印拣货单

点击打印拣货单
