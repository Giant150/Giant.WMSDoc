# 库位状态

可查看库位信息，可根据实际情况更改库位标志、状态等

##

![](01.png)

### 标志

&nbsp;&nbsp;&nbsp;&nbsp;1.当库位状态正常时，可正常使用库位

&nbsp;&nbsp;&nbsp;&nbsp;2.库位状态锁定时，说明库位被其他任务占用或故障，排查后解锁即可使用

&nbsp;&nbsp;&nbsp;&nbsp;3.库位状态损坏时，说明库位出现问题无法使用

### 状态

&nbsp;&nbsp;&nbsp;&nbsp;1.状态为启用时，可正常使用库位

&nbsp;&nbsp;&nbsp;&nbsp;2.状态为停用时，无法使用库位

### 空库位

&nbsp;&nbsp;&nbsp;&nbsp;开启时，说明此库位为空；关闭时，此库位被使用

### 有托盘

&nbsp;&nbsp;&nbsp;&nbsp;开启时，说明此库位有托盘；关闭时，此库位无托盘

&nbsp;&nbsp;&nbsp;&nbsp;当空库位和有托盘同时开启时，说明此库位上为空托盘
